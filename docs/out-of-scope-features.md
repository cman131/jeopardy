# Out of Scope Features

Features explicitly excluded from the initial build. Candidates for future iterations.

## Lobby

- **QR code on display screen** — scannable code alongside the game code so in-person players can join without typing the URL manually

## Board Editor

- **Multi-round boards** — attach a second board to a game so play continues into a second round after the first board is complete; each round is a full 6×5 board

## Game Mechanics

- **Daily Doubles** — special squares where a player can wager before seeing the clue
- **Wagers / Daily Double betting** — custom wager amounts per player per clue
- **Double Jeopardy round** — second round with doubled dollar values
- **Final Jeopardy** — all players wager secretly before a single final clue; scores revealed after
